Quick Start

Four steps to get JWL Assistant running for your first meeting.

1. Install

Run the JWL Assistant installer, or unzip the portable copy anywhere. No internet connection is required for the app itself; some optional features (background music engine, camera drivers) download once on first use if not already bundled.

2. Configure

Open Settings and connect the pieces you use:
  • OBS WebSocket (host/port + password if set)
  • Zoom meeting ID / display name for one-click join
  • PTZ camera hotkeys - see the PTZ Camera & Auto Frame guide
  • XR mixer IP, if you use one

3. Test

Before a real meeting: connect to OBS and confirm the status turns green, try the Cut hotkey, and check the camera preview shows live video (see Live Camera Preview if it stays black).

4. Ready

Use Auto Start / Auto Toggle settings so the app can automatically join Zoom, switch scenes, and toggle the Zoom camera around meeting time with no manual clicks needed once configured.
