PiP Media - Picture-in-Picture Setup Guide

The PiP button (the orange/green blip above the Media button) lets you toggle a video-capture source ON/OFF inside your Media OBS scene, creating a picture-in-picture overlay (e.g. live camera over a video).

How to set up in OBS

  1. Open OBS and switch to your Media scene.
  2. In the Sources panel, click "+" → "Video Capture Device" (or "Window Capture" / "Display Capture" for screen-based PiP).
  3. Name the source exactly as entered in the "OBS Source Name" field above (default: "PIP Video Capture").
    The name must match exactly, including capitalisation.
  4. Position and resize the source to the desired PiP location (e.g. bottom-right corner, approximately 25% of screen width).
  5. Right-click the source in OBS → "Hide" so it starts hidden. The PiP button will show/hide it on demand.
  6. Tick "Enable PiP Media toggle button" in this app so the blip appears in the main panel whenever OBS is connected.

How to use

  • Switch OBS to your Media scene first (use the Media button).
  • Click the PiP button (above the Media button) to toggle PiP ON (green) or OFF (orange).
  • PiP is automatically turned OFF when you leave the Media scene.

Tips

  • Use a "Video Capture Device" source pointing to a camera for a live speaker-over-media overlay during video playback.
  • The PiP button is only active when the Media scene is live on Program.
  • If the source name is wrong, check the OBS Sources panel for the exact spelling and update "OBS Source Name" in this app.
