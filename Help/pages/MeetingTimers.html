Meeting Times / Timers

▶ Watch: Timer functions and summary (video tutorial)

The app tracks your recurring meeting schedule so it can show a live countdown and automatically trigger actions (music stop, camera on, Zoom mute/unmute, scene switches, etc.) at the right moment before each meeting.

1. How to set meeting times

Open Settings → Meeting Times. Enter one meeting start time per line in the box, in the form: Day HH:MM am/pm
  • Thu 7:00 pm
  • Sun 11:00 am
You can use short (Sun, Mon, Tue, Wed, Thu, Fri, Sat) or full day names, and 12-hour (7:00 pm) or 24-hour (19:00) time. A line with no day (just a time) is treated as happening every day.
You can add extra lines for special events (e.g. a one-off CO visit time) - just add another line with that day/time.
The app always counts down to whichever line produces the soonest upcoming start time.

2. What the clock does during the countdown

The status bar shows the current time plus Next: Day h:mm tt (T-Xh Ym Zs) - a running countdown to the next scheduled meeting (or T+ if it just started).

In the last 5 minutes before start, the big clock switches to a large M:SS countdown and flashes color as a visual alert:

5:00 → 1:00 flashes green
1:00 → 0:15 flashes yellow
0:15 → 0:00 flashes red (only if enabled, see below)
Tick "Flash clock red for last 15 seconds before meeting start" in Meeting Times settings to enable the final red flash - otherwise it stays yellow through 0:00.
Once the meeting starts, the clock automatically returns to its normal time display a few seconds later.

3. Auto Start timers before the meeting

Several features can trigger automatically a configurable number of seconds before the next meeting starts - each has its own enable checkbox and a seconds field, found in their respective Settings sections:

Background Music auto-stops/fades out N seconds before start ("Auto-stop before meeting")
Auto Toggle starts automatically N seconds before start ("Auto start Auto Toggle")
OBS Virtual Camera turns on automatically N seconds before start
Zoom: Mute All mutes all participants N seconds before start
Zoom: Camera ON turns your Zoom camera on N seconds before start
Zoom: Unmute Host unmutes the host N seconds before start
Zoom: Focus Mode enables Focus Mode N seconds before start
Scene Picker rows each OBS scene row has its own "Seconds" + "Auto Start" - see Scene Picker
For each of these: tick the matching "Auto ..." checkbox, then set the seconds value to how far ahead of the meeting start you want it to fire (e.g. 40 seconds, 5 minutes = 300 seconds, etc.). Setting seconds to 0 disables that auto-action.
If you use several Auto actions together (e.g. Zoom Mute All + Camera ON + Unmute Host), stagger their seconds values by 5-10 seconds each so they don't fire at the exact same instant and conflict.

Meeting Mode (safety window)

Separately from the timers above, "Meeting Mode" defines a broader safety window around each meeting (default: starts 5 minutes before, lasts 95 minutes) during which background music is prevented from auto-starting. It can be turned on manually, or left on "Auto Guard" to engage automatically before every scheduled meeting - configurable in Meeting Times settings (Guard minutes, Auto Guard, Guard lead minutes).
