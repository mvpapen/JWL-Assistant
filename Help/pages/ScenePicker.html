Scene Picker - Setup Guide

This panel links each OBS scene to an XR mixer snapshot number. When a scene becomes active - whether switched by this app OR changed manually in OBS - the corresponding mixer snapshot fires automatically.

How it works

This app monitors OBS continuously. The moment OBS switches to a scene (by any means), the matching XR snapshot is loaded.
PTZ camera moves are configured entirely inside OBS - use OBS scene transitions or the obs-ptz plugin's "Auto PTZ" feature. Do NOT duplicate PTZ control here; it lives in OBS to avoid conflicts.

Column guide

Scene - the OBS scene name this row applies to. Must match exactly (case-insensitive).
Snapshot - XR mixer snapshot (1-10) to recall when this scene becomes active. Requires XR mixer connected.
FTB (Fade To Black) - tick this if switching TO or FROM this scene requires a camera move (PTZ). When FTB is active, Cut will:
  1. Switch to target scene instantly (OBS PTZ fires → camera starts moving immediately)
  2. Instantly cut to the Black scene (viewers see black)
  3. Hold black for "Hold black (ms)" while the camera travels
  4. Fade back to target using the original OBS transition
FTB triggers if EITHER the source OR target scene has FTB checked - so you only need to tick scenes that have a dedicated PTZ camera position.
Seconds - Auto Start delay: seconds after meeting start before this scene is automatically switched to. Set 0 to disable auto-start for this row.
Auto Start - tick to allow this row to auto-switch at meeting start.

How to set up OBS scenes

  1. Open OBS Studio.
  2. In the "Scenes" panel (bottom-left), click "+" to add scenes.
  3. Name them exactly as you want them to appear here (e.g. "Speaker", "All Stage", "Demo", "Table").
  4. Save your OBS scene collection.
  5. In this settings panel, click inside a Scene dropdown - available OBS scenes load automatically (OBS must be connected).

How to set up PTZ in OBS (not in this app)

PTZ camera control belongs in OBS, not here, to avoid numbering conflicts. Two recommended approaches:

Option A - obs-ptz plugin "Scene-linked presets" (recommended)

  1. Install obs-ptz from GitHub (search: obs-ptz release).
  2. In OBS: Tools → PTZ Controls → add and configure your camera.
  3. In the PTZ Controls dock, click the "PTZ" tab for your camera.
  4. Save camera positions as numbered presets (Recall 1, 2, 3…).
  5. Link a preset to a scene using "Scene PTZ Action": right-click the scene in the OBS Scenes list, add a "PTZ Action" under Sources +, select your camera and preset. OBS fires that PTZ preset automatically when the scene becomes Program (live), with no input from this app.

Option B - OBS Hotkeys (not recommended)

  1. In OBS: File → Settings → Hotkeys.
  2. Scroll to find "PTZ: Recall Preset N" entries.
  3. Assign a hotkey to each PTZ preset you use.
  4. Use an AutoHotkey script or stream deck to trigger the correct hotkey when you expect a scene switch.

Tips

  • Scenes must exist in OBS before they appear in the dropdown.
  • Connect OBS before opening Settings so scene names populate.
  • Snapshots fire for both app-initiated and manual OBS scene switches.
  • Auto Start rows fire in order of their Seconds value at meeting start.
  • Leave Snapshot blank (first item) for scenes that need no mixer change.
  • Tick FTB only on scenes with a physical PTZ camera position. Scenes like "Speaker Wide" (same camera, different zoom) don't need FTB.

Important - one camera, multiple scenes

If several scenes (e.g. Speaker/Table/Demo) share one physical PTZ camera, add the camera source once in OBS, then use "Add Existing" to place that same source into each scene - never create a separate "Video Capture Device" instance per scene. Separate instances each try to open their own exclusive handle to the same physical device, which can cause a scene to show black video when switched to (until OBS is restarted). Physical PTZ preset movement per scene should be handled by obs-ptz's "Scene PTZ Action" (see above), not by duplicating the source.
