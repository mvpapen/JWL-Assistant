Live Camera Preview - Requirements

This mode renders OBS's Virtual Camera output directly into the preview panel (via VLC), instead of polling OBS for screenshots every ~300 ms. It's smoother and eliminates freezing while Settings or other dialogs are open, but it needs a bit of setup.

1. DirectShow capture driver

This app bundles the driver needed to read a camera, so no extra install is normally required. If it's ever missing (e.g. a bundled file was removed), installing the full VLC Media Player once (videolan.org) also works - the app can borrow its driver instead.

2. Windows 11 camera sharing must be enabled

Make sure Windows is fully updated, then allow more than one app to use the same camera at once:
Settings → Privacy & security → Camera → "Let desktop apps access your camera"
Without this, OBS and this app can't both read the Virtual Camera at the same time.

3. OBS only provides one Virtual Camera output by default

If you need this app to preview a different feed than what another program (e.g. Zoom) is already using from OBS's Virtual Camera, install an OBS plugin that adds extra virtual camera outputs (search "OBS Multiple Virtual Camera" plugin), enable it, then pick the matching device name in Select Camera... in Settings.
