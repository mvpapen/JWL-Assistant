How Tesseract OCR Works

▶ Watch: Set up OCR and ROI (video tutorial)

Tesseract is a free, open-source OCR (Optical Character Recognition) engine. This assistant uses it to read text directly from your screen - specifically from the Region of Interest (ROI) you define - to detect the current Yeartext/keyword and switch OBS scenes automatically.

How to install Tesseract (if not already detected, or to add a different language)

This app automatically detects Tesseract if it's already installed (it checks common install folders and your system PATH) - it does not download or install it for you. Only follow these steps if the "Tesseract:" field in Settings is empty/incorrect, or if you need to add a language pack other than English.

  1. Download the Windows installer from the official GitHub release: github.com/UB-Mannheim/tesseract/wiki
  2. Run the installer (tesseract-ocr-w64-setup-*.exe for 64-bit).
  3. During install, note the path (default: C:\Program Files\Tesseract-OCR\tesseract.exe).
  4. In the Settings dialog, paste that path into the "Tesseract:" field, or use the Browse button to locate tesseract.exe.
  5. (Optional) To support non-English text (e.g. Spanish, French), install the extra language packs during setup or download .traineddata files from github.com/tesseract-ocr/tessdata.

How to set the ROI

  1. Open JWL (JW Library) and navigate to the screen showing the Yeartext/keyword.
  2. Click "Set ROI (drag)" - the screen dims on all monitors.
  3. Drag a rectangle around the keyword area on the media monitor (any monitor - the Settings dialog hides while you drag). Release the mouse to accept.
    Tip: if you choose a region that contains only numeric characters - such as a scripture number - you can avoid installing non-English language packs entirely.
  4. Click "Preview ROI" to verify the captured region looks correct.
Press ESCAPE or right-click at any time while dragging to cancel.
The ROI is stored in real screen pixels, so changing the Windows display scale does not require setting it again.
